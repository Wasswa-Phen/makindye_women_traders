# Hero Photography Assets

Place approved hero banner photography in this folder.

- **Current asset**: `makindye-hero.png` (`/images/hero/makindye-hero.png`)
- **Recommended dimensions**: `1920 × 1200 px` minimum (landscape, 16:10 or 16:9)
- **Format**: WebP or optimised PNG/JPEG (`< 500 KB` for production)
- **Registry reference**: `photos.hero` in `src/data/photos.ts`
